# Checklist final de homologação

## Automático

- [ ] TypeScript sem erros.
- [ ] Lint sem erros.
- [ ] Testes unitários e de integração verdes.
- [ ] Build de produção concluído.
- [ ] Migrações aplicadas do zero e reaplicadas sem erro.
- [ ] Imagem Docker construída.
- [ ] Health e readiness verdes.
- [ ] Smoke autenticado verde.

## Operacional

- [ ] Fornecedores em uso certificados.
- [ ] Portais em uso certificados.
- [ ] Custos reconciliados sem divergência.
- [ ] Uma oportunidade avaliada na decisão executiva.
- [ ] Uma proposta completa exportada.
- [ ] Um contrato cadastrado com vigência e saldo.
- [ ] Alertas de vencimento conferidos.
- [ ] Rollback conhecido e testável.

## Segurança

- [ ] `VPS_HOST_KEY` configurada.
- [ ] SSH por chave configurado.
- [ ] Login direto de root desativado.
- [ ] `FORCE_SECURE_COOKIES=true`.
- [ ] Conta de smoke sem privilégio administrativo.
