=============================================
   SISTEMA S2 - COMO USAR (WINDOWS)
=============================================

ANTES DE TUDO - instale o Node.js:
-----------------------------------
1. Abra o navegador (Chrome, Edge, etc.)
2. Digite na barra de endereço: nodejs.org
3. Baixe a versão LTS
4. Abra o arquivo baixado e conclua a instalação


O SISTEMA TAMBÉM PRECISA DE UM BANCO DE DADOS:
-----------------------------------------------
O S2 guarda produtos, propostas e preços em um
banco de dados MySQL. Essa parte é técnica:
peça ao responsável técnico para instalar o MySQL e
preencher o arquivo ".env" (variável DATABASE_URL).
Sem isso, o sistema pode abrir, mas não funcionará corretamente.


PRIMEIRA VEZ (instalar o sistema):
------------------------------------
1. Clique duas vezes em: INSTALAR.bat
2. Aguarde a conclusão da instalação
3. Quando aparecer "INSTALAÇÃO CONCLUÍDA", feche a janela


TODOS OS DIAS (para usar o sistema):
--------------------------------------
1. Clique duas vezes em: INICIAR.bat
2. Aguarde a tela de execução aparecer
3. O sistema abrirá no navegador
4. Não feche a tela de execução enquanto estiver usando o sistema


PARA FECHAR O SISTEMA:
-----------------------
1. Feche o navegador
2. Clique na tela de execução e pressione CTRL + C


PROBLEMAS:
-----------
Encaminhe ao responsável técnico a mensagem completa do erro,
o horário em que ocorreu e uma captura de tela.
