=============================================
   SISTEMA S2 - COMO USAR (WINDOWS)
=============================================

ANTES DE TUDO - instale o Node.js:
-----------------------------------
1. Abra o navegador (Chrome, Edge, etc.)
2. Digite na barra de endereço: nodejs.org
3. Clique no botão verde "LTS" para baixar
4. Abra o arquivo baixado e clique em:
   Próximo → Próximo → Instalar → Concluir


PRIMEIRA VEZ (instalar o sistema):
------------------------------------
1. Clique duas vezes em:  INSTALAR.bat
2. Aguarde terminar (pode demorar 2-3 minutos)
3. Quando aparecer "INSTALAÇÃO CONCLUÍDA", feche


TODOS OS DIAS (para usar o sistema):
--------------------------------------
1. Clique duas vezes em:  INICIAR.bat
2. Aguarde a tela preta aparecer
3. O sistema abre sozinho no navegador
4. NÃO feche a tela preta enquanto usar!


PARA FECHAR O SISTEMA:
-----------------------
1. Feche o navegador
2. Clique na tela preta e aperte CTRL + C
